# Scaling Laws 敏感性分析实施计划

## 0. 目标与输出
- 目标：评估 scaling laws 关键结论（指数、最优算力分配、成本效率拐点）的稳健性。
- 交付物：
  1) 敏感性分析报告（图+表+文字结论）
  2) 可复现实验脚本与配置
  3) 论文可直接引用的结果段落与附录

---

## 1. 分析对象定义
- 基础形式（示例）：
  - \(L(N, D) = A N^{-\alpha} + B D^{-\beta} + E\)
  - 或 \(L(C) = K C^{-\gamma} + E\)
- 其中：
  - \(N\): 参数量
  - \(D\): 训练 token 数
  - \(C\): 训练算力（FLOPs）
  - \(L\): 验证损失/困惑度/任务误差
- 主要结论对象：
  - 幂指数（\(\alpha,\beta,\gamma\)）
  - 固定预算下最优 \(N:D\) 配比
  - 成本效率最优点（quality-per-cost）

---

## 2. 变量与扰动设计
### 2.1 输入变量（优先级）
1. 拟合区间（小规模/中规模/大规模）
2. 拟合方法（OLS、加权回归、Huber/鲁棒回归）
3. 数据质量参数（去重率、过滤阈值、领域占比）
4. token 结构（通用/代码/高质量语料比例）
5. 训练预算与硬件效率假设（有效 FLOPs 折算系数）

### 2.2 扰动范围
- 局部扰动：±5%、±10%、±20%
- 全局扰动：在 log 空间做 LHS/Sobol 采样（建议 256~1024 组）
- 置信评估：每组配置建议 3~5 次重复或 bootstrap 重采样

---

## 3. 方法路线
## 3.1 局部敏感性（快速）
- 对关键参数计算弹性：
  \[
  S_x = \frac{\partial \ln y}{\partial \ln x}
  \]
- 输出：每个变量的局部影响排序、方向（正/负）与幅度。

## 3.2 全局敏感性（核心）
- 采用 Sobol 一阶/总效应指数：
  - 一阶指数：变量单独贡献
  - 总效应指数：变量及其交互总贡献
- 输出：全局敏感性条形图+交互热图。

## 3.3 稳健性与不确定性
- Bootstrap 拟合指数分布（均值、95%CI）
- 比较不同拟合方法与样本区间的一致性
- 判断“结论是否翻转”（例如最优 N:D 是否改变）

## 4. 实施步骤（按周）
### 第1周：基线复现
- 固化当前 scaling law 拟合脚本与数据版本
- 复现论文初稿主图（main.pdf 对应图表）
- 建立统一评估接口（输入配置 -> 输出指标）

### 第2周：局部敏感性
- 对 \(\alpha,\beta,\gamma\)、截距、噪声项做 ±扰动
- 生成 tornado 图（龙卷风图）和弹性表

### 第3周：全局敏感性
- 构建 Sobol/LHS 采样实验
- 并行运行实验并收集结果
- 计算一阶/总效应指数

### 第4周：稳健性与论文写作
- Bootstrap + 拟合方法对比 + 样本区间对比
- 形成“稳定结论 / 不稳定结论”清单
- 写入论文正文与附录

---

## 5. 指标与判据
- 主指标：
  - 验证 loss / perplexity
  - 预算约束下最优 N:D
  - 质量-成本比（quality per $ 或 per PF-day）
- 判据（示例）：
  - 若关键结论在 >80% 扰动场景保持不变 -> “稳健”
  - 若最优配比在合理扰动内频繁翻转 -> “高敏感，需谨慎外推”

## 7. 风险与缓解
- 风险：小规模点主导拟合 -> 结论偏移  
  - 缓解：分区间拟合 + 加权回归
- 风险：数据质量变量不可控  
  - 缓解：先做可控代理变量（去重率、困惑度过滤阈值）
- 风险：计算开销过大  
  - 缓解：先做 Morris/稀疏 Sobol 预筛，再对高影响变量精细采样

- 输出 3 张图：Sobol 条形图、最优配比漂移图、CI 图
