## 4. Existing Interior-Equilibrium Criterion (Must Reuse)

Canonical rule location:

- `src/competition_threshold.py`: `classify_interior_equilibrium(...)`.

Strict interior (`overall_interior_strict`) requires all three layers:

1. Teacher layer interior:
   - `p_star` not at lower/upper upstream price boundary.
2. Student layer interior:
   - student BR solver success and `D_star` not at lower/upper `D` boundary.
3. Downstream layer interior:
   - downstream solver success,
   - no fallback usage,
   - downstream prices not at bounds,
   - all shares strictly above `share_tol`,
   - residual norm within `solver_residual_tol`.

Weak interior (`overall_interior_weak`) is optional and uses `weak_share_tol` with a relaxed downstream condition.

This is the current `M` threshold classification rule and is frozen for comparability.
